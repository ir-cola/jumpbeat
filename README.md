# あがれ！ジャンプビート

曲の拍に合わせて階段を登り続けるリズムアクション。
押した瞬間の精度が、そのまま進める段数になる。

- **Unreal Engine 5.6 / C++**
- 個人開発・制作期間1週間・プチコン応募作品

---

## 遊び方

| キー | 動作 |
| --- | --- |
| `SPACE` | 跳ぶ |
| `A` / `D` | 押しっぱなしで斜め左・斜め右へ |
| `Enter` / 左クリック | 撃つ（降ってくる隕石を撃ち落とす） |

押したタイミングが拍にどれだけ近いかで進める段数が変わる。

| 判定 | 進む段数 |
| --- | --- |
| PERFECT | 2段。着地点に足場が無ければ自動で作られる |
| GREAT | 1段 |
| MISS | その場で足踏み。足場にヒビが入り、3回で崩れる |

赤いマスからは判定にかかわらず5段。
壁のマスには乗れず、跳ぶと弾き返される。
段が無いところへ跳ぶと落ちて終わり。

---

## 作りの要点

**BGMは自作合成。** `Tools/synth/` で numpy から波形を組み立てている。
音符を拍の整数倍の位置に置いて生成するので、BPM もオフセットも設計値そのもの。
拍位置の推定が要らず、同期のズレが原理的に起きない。

**判定は音の実再生位置が基準。** フレームの経過時間を足していくと処理落ちのぶん
だけ音楽から遅れるため、実際に鳴っている位置を受け取って毎フレーム寄せている。

**ジャンプは滞空時間が一定。** 1段でも5段でも着地までの時間は変わらない。
頂点の高さと滞空時間の両方を満たすよう、位置を直接補間して動かしている。

**地形は詰みが起きない生成。** 横に連続する穴と、連結した穴の塊に上限を設け、
1マスずつ確定させながら制約を確認する。経路探索は不要。
